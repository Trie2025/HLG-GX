# XLG

洛谷增强浏览器扩展 —— 把社区里零散好用的功能整合进一个扩展：统一开关、统一设置中心、统一主题，数据全部只存在本地，绝不外传。

| 项目 | 内容 |
| --- | --- |
| 适用浏览器 | Chrome / Edge（Chromium 内核，Manifest V3） |
| 适用站点 | www.luogu.com.cn |
| 版本 | V1.0.1（内部版本 1.0.1） |
| 数据 | 全部本地存储，无任何上传 |

## 功能

功能默认开启，随时可在设置中心（洛谷任意页面右下角齿轮，快捷键 `Ctrl+,`，或访问 `/st`）单独关闭。

### 阅读体验

- 全站字体优化：霞鹜文楷屏幕阅读版，代码块保留等宽字体，可排除 LaTeX 公式
- 全局圆角化、广告隐藏、隐藏求签
- 阅读进度条、回到顶部、文章目录
- 题目背景折叠、题解正文隐藏
- **保存站恢复**：专栏或剪贴板提示「无法查看」时，自动从保存站接口恢复内容并内联卡片展示；未收录时支持一键「保存到保存站」
- 讨论复制、复制为 Markdown、HTML 代码块运行
- 用户个人介绍、文章、剪贴板均使用洛谷官方渲染器渲染，效果与官网一致

### 做题效率

- 可交题解标记、原始难度显示（CF/AT）
- 难度标签：始终显示 / 悬停显示 / 隐藏
- 随机跳题（可排除已 AC）、任务计划随机跳转
- 自动勾选 O2、默认代码模板
- 代码折叠、行数统计、一键复制、危险代码扫描
- 编辑器自动排版、题单隐藏已 AC
- AI 题目分析（可选，需自行填入 API Key，默认关闭）

### 数据与可视化

- 等级分趋势图：历史 + 预测曲线，自研 SVG 渲染，点击直达比赛页
- 记分板等级分预测、提交记录测试点色卡
- 用户页增强：CCS / 咕值 / 粉丝卡片、等级分染色
- 主页收藏题单进度、比赛日历
- 数据概览：通过题数、提交数、排名一屏可见（需授权，仅本地）

### 社交

- 全网犇犇聚合、龙王排行
- 犇犇 LaTeX / Markdown 渲染，回复保真引用
- Ctrl+Enter 发犇犇、私信 Markdown 渲染、私信通知
- 发帖草稿自动保存

### 效率与专注

- Alt+S 全局搜索
- 专注模式、番茄专注锁
- 成就系统：AC 弹横幅 + 撒花
- 标点处理工具：Alt+H 唤起，Alt+1~5 快速切换
- 验证码自动识别（可选，需自行填入 Token）
- 跳出网站提示：外链先确认再新窗口打开

## 安装

1. 下载扩展 `.crx` 文件（或解压后的源码目录）
2. 浏览器地址栏输入 `chrome://extensions`
3. 打开右上角「开发者模式」
4. 把 `.crx` 拖进页面安装；或点「加载已解压的扩展程序」选择源码目录
5. 打开任意洛谷页面，右下角齿轮或 `Ctrl+,` 打开设置

> 安装后若页面无变化，请在扩展管理页重新加载扩展，并刷新洛谷页面。

## 目录结构

```
extension/
├── manifest.json          # Manifest V3 配置
├── background.js          # 后台 Service Worker（跨域代理 / 更新检查）
├── content/
│   ├── main.js            # 内容脚本（全部功能）
│   └── main.css           # 内容样式（含暗色适配）
├── lib/
│   └── luogu-renderer.min.js  # 洛谷官方渲染器（用于文章/剪贴板/个人介绍）
├── popup/                 # 工具栏弹出设置
└── icons/                 # 扩展图标（128/48/16）
```

## 开发

- 重新生成图标：`python gen_icon.py`（需 Pillow）
- 语法检查：`node --check extension/content/main.js`
- CRX 打包：`node make-crx.js`，无 Node 环境可用 `python pack.py`
- 修改后需在 `chrome://extensions` 重新加载扩展

## 隐私

- 所有设置、缓存、统计均存储在本地 `chrome.storage.local`
- 除用户主动开启的功能（保存站恢复、更新检查等）外，不向任何服务器发送数据
- 数据授权开关默认「待决定」，授权前不抓取任何统计

## 反馈

遇到问题可通过「更多设置 → 插件状态码」生成一串 `XLG|` 开头的加密压缩码（含用户名、全部功能开关、版本号与错误信息），复制后发给开发者即可快速定位环境。控制台可用 `__xlgDecodeStatus()` 解码。
